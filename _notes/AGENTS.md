# 本项目笔记入口（AGENTS）

> 本目录是 `D:/开源鸿蒙相关` 的分析工作区笔记，**只读记录，不参与任何交付物**。
> 建立时间：2026-10-24。所有内容由工具实测得出，未修改 `student_kit/` 与 `telephony_sms_mms/` 的任何文件。

## 一句话结论

`student_kit/` 不是待改造的项目代码，而是**课程作业的验收脚手架**：它用四个 Python 脚本把"AI 读源码得出的结论"强制绑定到可机器校验的源码锚点（`路径:行号#符号`），
最终产出物是 `report.md` + `slides.pdf`，评分的核心不是文采而是**锚点 0 FAIL**。

## 使用约定

1. 新增结论先落 `LOG.md`，稳定事实再提炼进 `MEMORY.md`。
2. `TODO.md` 只保留未完成项，完成后移到 `LOG.md` 并在 TODO 里删除。
3. 涉及版本/行号的记录**必须**同时写 tag 与 commit，否则半年后无法复现。
4. 本目录不得存放切片副本、报告草稿等交付物，避免与 `G12_<子系统>/` 混淆。
